# claude-skills

## How I Work with AI Tools

I use Claude with a set of custom "skills" — reusable instruction sets that shape how it responds, so I'm not re-explaining the same workflow every session.

**Skills I rely on:**

| Skill | What it does | Why it matters |
|---|---|---|
| **Caveman Mode** | Compresses responses ~75%, same accuracy | Saves time/tokens during long working sessions |
| **Humanizer** | Strips AI-sounding patterns from writing | Keeps drafts and docs sounding like an actual person wrote them |
| **Karpathy Guidelines** | Keeps code changes surgical — no scope creep | Avoids sprawling, unreviewable diffs on simple fixes |
| **Decision Framer** | Turns "should I do X or Y" into real options, criteria, and unknowns | Speeds up getting unstuck on technical or product decisions |
| **Hook Forge** | Generates 10 opening lines across different psychological triggers | Useful for writing docs, pitches, and outreach that don't get skipped |
| **Expand and Contract** | Sorts a half-formed idea into core / nice-to-have / maybe-later / out | Helps scope a feature or project before building |
| **Infographic Builder** | Turns text or data into a visual one-pager | Makes technical explainers easier to skim |
| **Find Skills** | Surfaces relevant capabilities for a task I'm not sure how to name | Cuts down on reinventing prompts from scratch |

No installs, no external tools — just instructions Claude applies directly when asked.
